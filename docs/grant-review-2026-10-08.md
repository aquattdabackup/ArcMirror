## What is already convincing, and what is not an extra requirement

Arc is necessary to the analyzer's main function: its native USDC amount, interface log representation, 18/6-decimal accounting and native USDC fee semantics drive the report. This matches [Arc's documented events](https://docs.arc.io/arc/references/usdc-system-events). The Lab supports reproducible demonstrations; the product is not claiming the Lab itself performs the read-only analysis.

Own deployed contracts, owner-created successes and mined failure, conservative evidence grades, public fixtures, a runnable CLI and working browser/CI checks substantiate technical credibility. Keeping Needs Review where coverage is unsupported strengthens accuracy; changing it to Verified for presentation would be a defect.

There is no identified need to spend more gas, create more demonstration transactions, publish npm, add wallet connection, implement memo/MCP, add more tools, or obtain an explorer verification badge solely to satisfy these published requirements. Those are not substitutes for a clear useful workflow. Preserve the current five demos and use the three tools only when they support the user's specific question.

Use [the short reviewer path](reviewer-walkthrough.md) and the two-sentence description in [the application draft](application-draft.md). No new broad feature work is needed for this recommendation. Neither this technical review nor the volume of commits establishes selection over other applicants.
