Captured 2026-09-24 through public, read-only JSON-RPC. These are public third-party transactions, not owner-generated ArcMirror demo vectors.

- `network.json`: primary RPC chain ID, observed head, USDC code/decimals, Memo candidate bytecode.
- `recent-transfer-logs.json`: fixed 128-block sample used to discover candidate transactions.
- `summary.json`: original four captured samples and primary RPC trace errors.
- `additional-samples.json`: dust discovery and native account code checks; no failure found in bounded search.
- `0x*.json`: five full transaction/receipt/block samples. Each includes provenance.
- `provider-capabilities.json`: mainnet chain checks plus call/prestate tracer responses from three documented fallback endpoints.
- `erc20-traces.json`: dRPC call tree and transaction-local state diff for the composed ERC-20 example.
- `balance-identities.json`: exact native/USDC delta calculations generated by the offline spike test.
- `validation.txt`: actual test output.

Run the frozen evidence checks without network or dependencies:

```powershell
node --test scripts/spike-evidence.test.mjs
```

To collect a **new** bounded observation, with network access:

```powershell
node scripts/read-only-spike.mjs
```

New runs are written below `docs/evidence/runs/<timestamp>/`, preserving these frozen samples. `extend-read-only-spike.mjs` and `inspect-erc20-spike.mjs` are investigation utilities for this snapshot, not application modules or a general-purpose verifier.

The application now generates canonical JSON/keccak256 report digests. Three frozen expected application outputs and their provenance are available in `vectors/`; they are public third-party examples, not owner-created demos.
